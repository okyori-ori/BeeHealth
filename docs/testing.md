# Тестовые сценарии BeeHealth

Начальные условия приведены для учебной базы после `schema.sql` и `seed.sql`. Даты примеров рассчитываются относительно дня загрузки данных.

| ID | Начальное условие | Действие | Ожидаемый результат | Фактический результат и статус |
|---|---|---|---|---|
| BH-01 | Запущено главное окно, есть тестовые пасеки | Добавить пасеку «Северная», изменить местоположение, найти её, подтвердить удаление | Строка появляется, меняется, находится и после удаления отсутствует | PASS · Тестовая пасека создана, изменена и удалена через слой данных. |
| BH-02 | В базе три улья | В «Ульях» найти «Луговая», далее ввести «Несуществующая» | Сначала два улья «Луговой», затем сообщение «Записи не найдены» | PASS · Пустой поиск загрузил все записи в шести разделах, точный поиск нашёл тестовую пасеку. |
| BH-03 | Есть семья и вид мероприятия | Создать осмотр на дату заселения или позже, выбрать выполненный вид | В журнале появляется осмотр, в профилактике — выполненное мероприятие с датой и № осмотра | PASS · Осмотр и мероприятие сохранены и проверены в SQL Server. Связанные записи также видны в окне. |
| BH-04 | Известна дата заселения «Рябинки» | Сохранить осмотр за день до заселения | Появляется сообщение о дате, новых записей нет | PASS · Сервис отклонил дату раньше заселения, новых записей нет. |
| BH-05 | Есть запланированное мероприятие | Включить «Выполнено», оставить дату пустой и сохранить | Требуется дата выполнения, мероприятие остаётся запланированным | PASS · Сервис отклонил выполнение без даты, новых записей нет. |
| BH-06 | Есть тестовая семья и действующий вид профилактики | Запустить `dotnet run --project checks`. Проверка создаёт осмотр, вставляет первое мероприятие и пробует вставить второе с несуществующим видом | SQL Server выдаёт ошибку FK 547. Контрольная выборка подтверждает отсутствие осмотра и первого мероприятия | PASS · SQL Server вернул ошибку FK 547. Осмотр и первое мероприятие отсутствуют. |
| BH-07 | Загружены исходные примеры | Открыть сводку. Для осмотров и выполненных мероприятий отобрать период со дня загрузки минус 7 дней до дня загрузки включительно | По одной активной семье в обеих пасеках, один осмотр, одно выполнение, план за пределами периода | PASS · Сводка загрузилась в окне. Запросы проверили перечень пасек, статусы и нижнюю границу периода. |
| BH-08 | Пасека «Луговая» содержит ульи | Попробовать удалить её и подтвердить операцию | Видно сообщение о связанных записях, пасека и ульи сохранены | PASS · SQL Server отклонил удаление пасеки с ульями. |

Команда `dotnet run --project checks` выполняет серверную часть BH-03–BH-06. Для приёмки интерфейса выполните те же сценарии вручную там, где приведены действия в окне приложения. Прогон сохранения и отката требует прав на вставку и удаление в учебной базе.

## Проверка сборки

Сборка Release приложения и проверочной программы завершилась с 0 ошибок и 0 предупреждений. Главное окно BeeHealth открылось. При развёртывании базы клиент вернул ошибку SQL Network Interfaces 52 — на проверочном компьютере отсутствует SQL Server LocalDB. Фактические результаты SQL-сценариев будут доступны после прогона на установленном экземпляре.
