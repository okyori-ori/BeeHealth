# BeeHealth

Настольная система учёта пчелиных семей. Пасечник ведёт справочники пасек и ульев, регистрирует состояние семей при осмотрах, планирует профилактику и отмечает выполнение.

## Возможности

- Добавление, просмотр, изменение и удаление записей во всех шести разделах. Семью можно перевести в архив, сняв отметку «Семья активна».
- Поиск по названиям и связанным сведениям. Отбор осмотров и профилактики по датам.
- Сохранение осмотра и выполненных в этот день мероприятий одной транзакцией.
- Сводка по активным семьям, осмотрам, запланированным и выполненным мероприятиям.

## Запуск на Windows

1. Установите .NET 8 SDK и Microsoft SQL Server. Для учебного запуска подходит [SQL Server Express LocalDB](https://learn.microsoft.com/sql/database-engine/configure-windows/sql-server-express-localdb).
2. Откройте PowerShell в корне проекта, где находятся папки `src` и `database`.
3. Создайте базу и наполните её демонстрационными данными одной командой. Запускайте эту команду один раз для новой базы.

   ```powershell
   dotnet run --project checks -- --setup
   ```

   В SSMS можно выполнить те же скрипты вручную в порядке `database/schema.sql`, затем `database/seed.sql`.
4. Запустите интерфейс.

   ```powershell
   dotnet run --project src
   ```

По умолчанию используется `(localdb)\MSSQLLocalDB`, база `BeeHealth` и учётная запись Windows. Для другого экземпляра задайте переменную в том же окне PowerShell перед созданием базы и запуском приложения.

```powershell
$env:BEEHEALTH_CONNECTION = 'Server=.\SQLEXPRESS;Database=BeeHealth;Integrated Security=True;TrustServerCertificate=True;Connect Timeout=5'
```

Для сборки сверху можно открыть `src/BeeHealth.csproj` в Visual Studio с компонентом «Разработка классических приложений .NET». Стек проекта — C#, WPF на .NET 8 и Microsoft.Data.SqlClient 5.2.3.

## Как показать проект

1. Откройте пасеки, ульи и карточку «Рябинка» в разделе «Семьи».
2. Создайте осмотр на сегодняшнюю дату. Выберите один или несколько выполненных видов профилактики и сохраните. В разделе «Профилактика» найдите записи с номером осмотра.
3. Попробуйте сохранить осмотр раньше даты заселения. Затем отметьте мероприятие выполненным без даты. Приложение должно показать причину отказа.
4. Откройте сводку, задайте период и переключите вкладки. Для демонстрации реального отката на учебной базе выполните команду ниже.

   ```powershell
   dotnet run --project checks
   ```

Проверки используют тот же сервис, что и WPF-приложение. Программа рассчитана на отдельную тестовую базу без одновременных изменений. Она удаляет успешную контрольную запись после прогона.
